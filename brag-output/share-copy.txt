=== LINKEDIN ===
Gitlines is a native macOS widget for GitHub activity — exact commits, additions, deletions, net change, peak intervals and repository rankings, pulled across every branch and deduplicated by SHA.

It ships with six complete visual themes: a restrained dark default, a translucent Glasshouse, a terminal-green Phosphor, a newsprint Broadsheet, a four-colour Arcade, and a modular Blockwork studio you can rearrange per widget size. Every one of them renders the identical snapshot — changing the look never changes the numbers.

Four purpose-built widget sizes. Fine-grained read-only tokens, stored in Keychain. macOS 14+.
