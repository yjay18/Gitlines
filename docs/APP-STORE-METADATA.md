## Description

Gitlines brings your real GitHub activity to the macOS desktop.

See commits, additions, deletions, net change, active periods, peak activity and repository rankings in native WidgetKit widgets. Choose daily, weekly or monthly views independently for each widget, then switch between fixed calendar periods and rolling windows in the app.

Open Gitlines for a deeper historical dashboard: explore repositories, search and filter your catalogue, compare projects, inspect activity trends and browse a 13-week activity calendar.

Make it yours with six distinct visual themes—Default, Blockwork, Glasshouse, Phosphor, Broadsheet and Arcade—across small, medium, large and extra-large widgets.

Gitlines connects directly to GitHub using read-only access. Credentials stay in the app-scoped macOS Keychain. Display-ready widget snapshots stay in the shared App Group container. Gitlines has no advertising, tracking or developer-operated analytics.

Gitlines is not an official GitHub product.

## App Review notes

Gitlines includes clearly labelled sample data when no GitHub account is connected, so the dashboard, repository presentation, themes and widget configuration can be evaluated without a review account.

To test live data, open Connections, choose Sign in with GitHub, copy the short device code to the GitHub verification page and approve read-only access. Manual fine-grained tokens are available under Advanced connections for organization access.

The host app stores GitHub credentials only in the app-scoped data-protection Keychain. The widget extension receives display-ready snapshots through App Group `group.com.yjay18.widtget`; it never receives credentials or makes authenticated requests.
