numbers
Not a contribution graph. The arithmetic of your day.

  

    
--branches allDiscovers recent work beyond the default branch.Commits reachable from more than one branch are deduplicated by repo + SHA.

    
--period daily|weekly|monthlyA period per widget, cycled from the widget itself.Calendar windows, or rolling 24h / 7d / 30d. Both cached so the switch is instant.

    
--stats exactAdditions, deletions, net, active intervals, peak, averages, repo rankings.Totals come from GitHub's per-commit statistics, not estimates.

    
--owner personal|orgConnect your account, add organizations independently.Fine-grained read-only tokens, one per owner, stored only in Keychain.

    
--boundaryThe widget extension never sees a token.The host app fetches and writes snapshots to the App Group; the widget only reads that cache.

    
--on-failure staleKeeps the last good snapshot and marks it stale.Lightweight refresh from the widget, full branch discovery from the app.
