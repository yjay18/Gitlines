What it counts.

Every branch

Work beyond main

Discovers recent activity on any branch and deduplicates commits that appear on more than one, by repository and SHA.

Daily · Weekly · Monthly

Per-widget periods

Pick a period for each widget and cycle it right from the widget. Calendar windows or rolling 24h, 7d, 30d.

Exact stats

Additions, deletions, net

Totals come from GitHub's per-commit statistics. Plus active intervals, peak activity, averages and repo rankings.

Orgs too

Personal and organization repos

Connect your account, then add organizations independently with fine-grained, read-only tokens. One token per owner.

Keychain only

The widget never sees a token

The host app talks to GitHub and writes snapshots to the App Group. The widget extension only reads that cache.

Resilient

Stale, not blank

If a refresh fails the widget keeps the last good snapshot and marks it stale. Lightweight refreshes from the widget, full discovery from the app.
