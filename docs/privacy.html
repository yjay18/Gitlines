Gitlines Privacy Policy

Last updated 14 September 2026

Gitlines does not collect your data. There is no Gitlines account, server, advertising, analytics, or telemetry. Information stored by the app stays on your Mac. Gitlines contacts GitHub only when you ask it to connect or refresh.

Information stored on your Mac

  • GitHub credentials — access and refresh tokens from GitHub sign-in, or a personal access token you provide, are saved in the macOS Keychain.
  • Cached GitHub activity — your GitHub username, repository names, and commit, pull-request, and review counts with timestamps are stored in the app's shared container so its widgets can render without network access.
  • Preferences — themes, widget layouts, periods, refresh intervals, and similar settings.

Gitlines and its widget extension use this local information. The widget receives display-ready snapshots and never receives GitHub credentials.

Network connections

Gitlines connects directly to GitHub over HTTPS:

  • github.com — to authorize GitHub sign-in, manage repository access, or open token settings.
  • api.github.com — to read the activity and repository information you asked Gitlines to display.

Requests are not sent through a server operated by the Gitlines developer. GitHub handles these requests under GitHub's Privacy Statement.

What Gitlines does not do

  • No analytics, telemetry, crash reporting, advertising, or tracking.
  • No sale or disclosure of your data.
  • No third-party SDKs or libraries.

Deleting your data

Choosing Disconnect GitHub deletes stored GitHub credentials and cached activity. You can also revoke Gitlines from your GitHub settings.

Deleting the app removes its cached activity and preferences, but macOS may retain Keychain items. Disconnect GitHub before uninstalling if you want Gitlines to delete those credentials.

Children

Gitlines is a developer tool and is not directed at children.
